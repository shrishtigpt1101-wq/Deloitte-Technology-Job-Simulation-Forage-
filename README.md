# Deloitte Technology Job Simulation (Forage)

Link: https://www.theforage.com/simulations/deloitte-au/technology-fz0w

## Overview

I completed Deloitte's Technology Virtual Experience Program on Forage, where I got a chance to work on tasks similar to what a technology consultant would do. The simulation helped me understand how real-world business problems are approached using technology.

## What I Did

- Worked on analyzing business problems and thinking of practical tech-based solutions.
- Performed basic coding and data-related tasks.
- Created a simple dashboard/solution idea based on given requirements.
- Explored cybersecurity concepts by identifying possible risks.
- Looked into data to understand patterns and issues.

## Implemented Task

This repository includes the data-format conversion task from the simulation. The Python solution in `Task 1/main.py` reads device telemetry data from two different JSON formats and converts both into one unified output format.

Files included:

- `Task 1/main.py` - Python conversion logic and unit tests.
- `Task 1/data-1.json` - Input data in format 1.
- `Task 1/data-2.json` - Input data in format 2.
- `Task 1/data-result.json` - Expected unified output.
